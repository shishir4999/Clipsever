# ClipSaver — ভিডিও/অডিও ডাউনলোডার (Android)

লিংক পেস্ট করলে বা অন্য অ্যাপ থেকে Share করলে ভিডিওর সব রেজোলিউশন আর অডিও ফরম্যাট (MP3, M4A) দেখায়। যেটা বাছবে সেটা ব্যাকগ্রাউন্ডে ডাউনলোড হয়ে `Downloads/ClipSaver` ফোল্ডারে সেভ হয়।

ভেতরের ইঞ্জিন: [yt-dlp](https://github.com/yt-dlp/yt-dlp) (YouTube, Facebook, Instagram, TikTok, X, Vimeo সহ ১০০০+ সাইট) + FFmpeg (ভিডিও-অডিও জোড়া লাগানো আর MP3 বানানো)। Android-এ চালানোর লাইব্রেরি: youtubedl-android।

---

## APK বানানোর নিয়ম (Android Studio ছাড়া, সম্পূর্ণ ফ্রি)

বিল্ডটা GitHub-এর সার্ভারে হবে। তোমার পিসিতে কিছু ইনস্টল করতে হবে না।

1. [github.com](https://github.com) এ একটা অ্যাকাউন্ট খোলো (না থাকলে), তারপর **New repository** বানাও। নাম যা খুশি, যেমন `clipsaver`। Public রাখলে Actions-এর কোনো সীমা নেই।
2. এই ZIP এক্সট্র্যাক্ট করো। ভেতরের **সব ফাইল আর ফোল্ডার** (লুকানো `.github` ফোল্ডারসহ) repository-তে আপলোড করো: **Add file → Upload files** → ফোল্ডারের ভেতরের সবকিছু টেনে এনে ছাড়ো → **Commit changes**।
   - `.github` ফোল্ডার আপলোড না হলে: **Add file → Create new file** চাপো, নামের ঘরে লেখো `.github/workflows/build-apk.yml`, তারপর এই ZIP-এর ভেতরের একই নামের ফাইলের লেখা কপি করে পেস্ট করো।
3. repository-র **Actions** ট্যাবে যাও। **Build APK** বেছে **Run workflow** চাপো (আপলোড করার সময়ই অটো চালু হয়ে যেতে পারে)।
4. ৮–১৫ মিনিট পর সবুজ টিক এলে ওই রান খোলো। একদম নিচে **Artifacts** অংশে `ClipSaver-APKs` ডাউনলোড করে unzip করো।
5. ভেতরে দুটো APK পাবে:
   - `app-arm64-v8a-release.apk` → প্রায় সব আধুনিক ফোনের জন্য। **আগে এটা ট্রাই করো।**
   - `app-armeabi-v7a-release.apk` → শুধু পুরনো ৩২-বিট ফোনের জন্য। প্রথমটা "App not installed" বা "incompatible" বললে এটা দাও।
6. ফোনে APK ইনস্টল করো। "Install unknown apps" অনুমতি চাইলে দিয়ে দাও।

## ব্যবহার

- **পদ্ধতি ১:** অ্যাপ খুলে লিংক পেস্ট করো → **ফরম্যাট দেখুন** চাপো → নিচ থেকে পপআপ আসবে → **ভিডিও** ট্যাবে সব রেজোলিউশন, **অডিও** ট্যাবে MP3/M4A → যেটা চাও সেটায় ট্যাপ করো।
- **পদ্ধতি ২:** YouTube/Facebook/Instagram/ব্রাউজারে ভিডিওর **Share** চাপো → তালিকা থেকে **ClipSaver** বাছো। অ্যাপ নিজেই ফরম্যাট বের করে পপআপ দেখাবে।
- প্রথমবার অ্যাপ খুললে "ডাউনলোড ইঞ্জিন প্রস্তুত হচ্ছে" দেখাবে। কয়েক সেকেন্ড লাগে। এরপর অ্যাপ নিজে yt-dlp আপডেট করে নেয়। ওপরের ডানের রিফ্রেশ বাটন দিয়ে হাতেও আপডেট করা যায়।
- ডাউনলোড একটার পর একটা চলে। অ্যাপ বন্ধ করলেও নোটিফিকেশনসহ চলতে থাকে।

## জেনে রাখো

- **YouTube মাঝে মাঝে আটকাবে।** YouTube প্রায়ই নিয়ম বদলায় (JavaScript চ্যালেঞ্জ, "Sign in to confirm you're not a bot")। এ ধরনের অ্যাপ, এমনকি Seal বা YTDLnis-ও, তখন কিছুদিন কাজ করে না, যতক্ষণ না yt-dlp-র নতুন আপডেট আসে। আপডেট বাটন চেপে আবার চেষ্টা করো। Facebook, Instagram, TikTok, X, Vimeo-তে সমস্যা অনেক কম।
- **Google Play Store-এ দেওয়া যাবে না।** YouTube ডাউনলোডার Play Store-এর নিয়মে নিষিদ্ধ। শুধু APK হিসেবে ইনস্টল করে ব্যবহার করা যাবে।
- Android ১০ বা তার ওপরের ফোন লাগবে।
- প্লেলিস্ট/চ্যানেলের লিংক এখনো সাপোর্ট করে না। একটা একটা ভিডিওর লিংক দিতে হবে।
- ডাউনলোডের তালিকা অ্যাপ পুরোপুরি বন্ধ করলে মুছে যায়। তবে ফাইলগুলো `Downloads/ClipSaver`-এ থেকে যায়।
- APK-টা debug key দিয়ে সাইন করা, নিজের ব্যবহারের জন্য ঠিক আছে।
- নিজের ভিডিও বা যেসব কনটেন্ট ডাউনলোডের অনুমতি আছে, সেগুলোর জন্য ব্যবহার করো। কপিরাইটেড কনটেন্টের দায় তোমার।

## বিল্ড ফেইল করলে (লাল ❌ এলে)

কোডটা এমন জায়গায় লেখা হয়েছে যেখানে Android SDK ছিল না, তাই ওখানে কম্পাইল করে দেখা যায়নি। প্রথম বিল্ডে ছোট কোনো এরর আসতেই পারে (সাধারণত লাইব্রেরির ফাংশনের নাম বা সিগনেচার নিয়ে)। হলে:

1. Actions-এ লাল রানটা খোলো → **Build release APKs** ধাপ খোলো → লাল `e: ...` লাইনগুলো কপি করো।
2. সেটা আমাকে পাঠাও। ঠিক করা ফাইল দিয়ে দেব, ওই ফাইলটা repository-তে বদলে আবার Run workflow দিলেই হবে।

## ফাইলের গঠন

| ফাইল | কাজ |
|---|---|
| `Downloader.kt` | yt-dlp দিয়ে ভিডিওর তথ্য আনা, রেজোলিউশনের তালিকা বানানো, ডাউনলোড করে Downloads-এ সেভ করা |
| `DownloadService.kt` | ব্যাকগ্রাউন্ডে কিউ চালানো ও নোটিফিকেশন |
| `Downloads.kt` | ডাউনলোড কিউ |
| `Engine.kt` | yt-dlp/FFmpeg চালু করা আর আপডেট |
| `HomeScreen.kt`, `Components.kt` | স্ক্রিন, ফরম্যাট পপআপ, ডাউনলোড কার্ড |
| `MainViewModel.kt`, `MainActivity.kt` | লিংক নেওয়া ও Share ইন্টেন্ট |
| `res/values-bn/strings.xml` | বাংলা UI লেখা (ফোনের ভাষা বাংলা হলে অটো দেখাবে) |
